# 눈꽃마을 안전 광장 디자인 문서

사용자와 사용 맥락은 PRD.md 3장에 있다. 이 문서는 거기서 나온 화면 규칙을 적는다.

## 1. 화면 규칙
- 글자와 버튼 크기: 터치 영역을 크게 만든다. 기본 버튼 높이 76px 이상, 게임 조작 버튼(XL)은 104px, 안내 글자 28~34px. 교실 태블릿에서 확인하며 조정한다.
- 버튼 위치: 같은 기능의 버튼은 모든 화면에서 같은 자리에 둔다.
- 한 화면의 정보량: 시작 카드에는 규칙 1장, 결과 화면에는 배운 규칙 한 문장만 둔다.
- 문장 수준과 말투: 쉬운 말과 그림 상징을 함께 쓴다. 모든 글자를 음성으로도 들려준다.
- 숫자: 큰 숫자 대신 온도계, 코인 아이콘 개수처럼 그림으로 보여 준다.
- 접근성:
  - 게임오버 없이 실패하면 바로 앞에서 다시 하고, 왜 실패했는지 한 문장으로 알려 준다.
  - 한 판은 3~5분 길이로 만든다.
  - '가' 수준에는 시간 제한을 두지 않는다.
  - 불이 나거나 물에 빠지는 장면은 연기, 경보음, 물보라 같은 상징으로만 보여 준다.

## 2. 분위기와 스타일
- 전체 인상: bloxity.io처럼 블록풍 3D 겨울 마을. 카메라는 비스듬히 내려다보는 고정 쿼터뷰.
- 글꼴: KERIS 학교안심 글꼴(hakgyoansim-font-kit).
- 색: 겨울 하늘색 바탕(#cfeaff), 기본 버튼 파랑(#2b8be0), 강조·다시하기 주황(#ff8a3d), 성공 초록(#3dbd7d), 위험 표시 빨강(#ff3b30). 눈 쌓인 흰색 블록 위에 채도 높은 색을 한두 개만 쓴다.
- 캐릭터와 건물: 처음에는 코드에서 상자를 조합해 만들고, 나중에 사용자가 직접 만든 에셋으로 바꾼다.

## 3. 화면 목록

| 화면 | 목적 | 주요 요소 |
|---|---|---|
| 시작 | 학생 입장 | 학급 코드(저장 시 생략), 캐릭터 고르기, 그림 비밀번호 |
| 눈꽃마을 광장 | 미니게임 고르기, 진행 확인 | 입구 4개(빙판 골목, 우리 집, 눈밭, 개울가), 가운데 큰 눈사람, 내 아바타, 옷장 버튼 |
| 시작 카드 | 규칙 미리 알기 | 규칙 1장, 음성 |
| 플레이 | 규칙 연습 | 미니게임 4종별 조작(PRD 4-2) |
| 결과 | 배운 것 정리, 보상 | 배운 규칙 한 문장, 다시 듣기, 장비 받기, 광장으로 |
| 내 옷장 | 장비 입고 벗기 | 받은 장비 목록, 착용 미리보기 |
| 교사 페이지 | 학급 운영 | 학급·학생 등록, 학생별 가·나·다 지정, 클리어 현황 표 |

## 4. 공통 요소
- 버튼과 입력: 큰 버튼에 그림, 짧은 글, 음성을 함께 둔다. 펭귄걸음 오비는 큰 버튼 두 개(천천히 걷기 / 뛰기)로 조작한다.
- 피드백:
  - 실패: 가장 가까운 지점으로 부드럽게 되돌리고 이유를 한 문장으로 알려 준다.
  - 성공: 장비를 받고 눈사람 조각이 채워진다. 다시 하면 별이 더 붙는다.
  - 완료: 4개를 모두 깨면 마을에 불이 켜지는 축제 연출과 '겨울 안전 지킴이' 배지.
- 소리와 움직임: 모든 안내를 음성으로 들려준다. 위험 상황은 연기, 경보음, 물보라 같은 상징으로만 표현한다.
