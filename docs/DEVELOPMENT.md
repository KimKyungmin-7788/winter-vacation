# 눈꽃마을 안전 광장 개발 문서

기술 스택은 AGENTS.md에, 만드는 이유와 범위는 PRD.md에 있다.

## 1. 배포와 운영
- 배포 위치: Vercel
- 로그인:
  - 학생: Supabase 익명 로그인 후 학급 코드, 캐릭터, 그림 비밀번호로 학생 기록에 연결한다. 교실 태블릿에는 학급 코드를 저장해 두어 입력을 생략할 수 있게 한다.
  - 교사: Supabase Auth 계정. 로그인 방식은 PRD 열린 질문에 있다.
- 보안과 개인정보:
  - 학생은 별명만 받는다. 실명, 사진, 이메일은 받지 않는다.
  - 모든 테이블에 RLS를 건다. 학생은 자기 기록만, 교사는 자기 학급 기록만 읽고 쓴다.
  - 그림 비밀번호는 해시로 저장한다.
  - 비밀 키는 클라이언트 코드에 넣지 않는다.
  - 공개 배포 전에 edu-app-launch 점검(보안 헤더, 개인정보처리방침, 학생 정보 유출 점검)을 한 번 돌린다.
- 성능: 태블릿이 버거워하면 그림자를 끄고 해상도(픽셀 비율)를 제한한다. 그래도 무거우면 2.5D로 바꿀지 사용자와 상의한다.
- 음성: 모든 안내 문구를 Google Cloud TTS로 미리 mp3로 만들어 앱에 넣는다. 실행 중에 TTS를 부르지 않는다.

## 2. 데이터
- 저장 위치: Supabase
- 저장하는 것:

| 테이블 | 주요 컬럼 | 용도 |
|---|---|---|
| `classes` | id, teacher_id, name, class_code | 학급과 입장 코드 |
| `students` | id, class_id, nickname, character_key, pin_hash, level(가/나/다), equipped(json) | 학생 별명, 그림 비밀번호, 수준, 착용 장비 |
| `progress` | student_id, game_key, level, cleared, stars, play_count, last_played_at | 미니게임별 클리어 상태 |
| `inventory` | student_id, item_key, acquired_at | 받은 장비 |
| `mistakes` | student_id, game_key, level, mistake_key, created_at | 자주 틀리는 상황 기록(예: run_on_ice, heater_near_curtain) |

- `mistakes`는 이번 범위에서는 쌓아 두기만 한다. 나중에 교사 대시보드로 넓힐 때 쓴다.
- 저장하지 않는 것: 학생 실명, 사진, 이메일, 녹음.

## 3. 개발 단계

### 1단계: 광장 + 펭귄걸음 오비
- 만드는 것: 프로젝트 세팅, 학교안심 글꼴 적용, 쿼터뷰 광장, 바닥 터치 이동, 입구 4개(오비만 연결), 상자 조합 캐릭터, 펭귄걸음 오비 '가' 수준(버튼 2개, 빙판 마찰, 체크포인트), 시작 카드와 결과 화면. 진행은 아직 저장하지 않는다.
- 완료 확인 방법: 교실 태블릿에서 광장을 터치해 걸어가고, 오비에 들어가 빙판에서 뛰면 미끄러져 체크포인트로 돌아가고, 천천히 걸으면 통과한다. 결과 화면에서 미끄럼 방지 신발을 받고 광장으로 돌아온다. 이 과정이 태블릿에서 끊김 없이 돌아간다.

### 2단계: 나머지 미니게임 3종 '가' 수준
- 만드는 것: 따끈따끈 우리집 타이쿤, 체온 지킴이 눈밭 탐험, 얼음 위는 안 돼! 순찰대(혼자 + NPC 동료)의 '가' 수준.
- 완료 확인 방법: 미니게임 3종을 '가' 수준으로 처음부터 끝까지 할 수 있고, PRD 4-2의 '가' 수준 내용이 모두 들어 있다. 실패하면 게임오버 없이 바로 앞에서 다시 시작한다.

### 3단계: 보상과 진행 저장
- 만드는 것: 장비가 아바타에 붙기, 눈사람 조각 완성, 4개 클리어 시 마을 축제와 배지, 내 옷장, Supabase 테이블과 RLS, 학생 로그인(학급 코드 + 캐릭터 + 그림 비밀번호). 학생 데이터는 테스트용으로 미리 넣어 확인한다.
- 완료 확인 방법: 새로고침하거나 다른 태블릿에서 같은 학생으로 로그인해도 장비와 진행이 그대로 남아 있다. 다른 학생의 기록은 읽을 수 없다(RLS 확인).

### 4단계: 음성 안내
- 만드는 것: 학생에게 보이는 모든 문구의 mp3 연결, 결과 화면의 '다시 듣기'.
- 완료 확인 방법: 음성이 빠진 문구 목록이 0개다. 모든 화면에서 글을 읽지 않고 음성만으로 진행할 수 있다.

### 5단계: 교사 페이지
- 만드는 것: 교사 로그인, 학급 만들기와 학급 코드 발급, 학생 등록(별명, 캐릭터, 그림 비밀번호), 학생별 수준 지정, 클리어 현황 표.
- 완료 확인 방법: 교사가 학급과 학생을 만들고, 학생이 그 정보로 로그인하면 지정한 수준으로 게임이 열린다. 학생이 미니게임을 깨면 현황 표에 반영된다.

### 6단계: 나·다 수준
- 만드는 것: 미니게임 4종의 '나', '다' 수준.
- 완료 확인 방법: 수준별 차이가 PRD 4-2 표대로 들어 있다. 교사가 수준을 바꾸면 다음 판부터 바뀐 수준으로 열린다.

### 7단계(2차): 순찰대 실시간 협동
- 만드는 것: Supabase Realtime으로 같은 학급 학생들이 순찰대 맵을 함께 쓰고, 순찰 점수 하나를 같이 채운다.
- 완료 확인 방법: 태블릿 2대 이상에서 서로의 캐릭터가 보이고, 한 학생이 찾은 결과가 모두의 순찰 점수에 반영된다.

## 4. 일정
- 정해진 기한 없음. 적용 시기와 완성 기한은 PRD 열린 질문에 있다.

## 5. 구현 기록 (에이전트가 정한 세부 수치)
사용자가 "문서대로 끝까지 만들어"라고 위임해서, 문서에 없던 세부는 아래처럼 정했다. 교실에서 해 보고 고친다.

- **단계 진행**: 1~7단계를 모두 구현했다. 단계마다 승인을 받지 않고 이어서 만들었다.
- **저장소 두 가지**: `.env`에 Supabase 키가 있으면 서버(`supabase/schema.sql`), 없으면 이 태블릿 안 저장(체험 모드). 화면 코드는 `lib/backend.ts` 인터페이스만 쓴다.
- **학생 쓰기는 전부 RPC**: 학생(익명 로그인)은 테이블에 직접 쓰지 못하고 `record_progress`, `grant_items`, `set_equipped`, `log_mistakes` 함수로만 쓴다. `students.pin_hash`는 누구도 읽을 수 없다. 그림 비밀번호 5번 틀리면 1분 잠금.
- **수준은 학생 1개(`students.level`)**: 미니게임마다 따로 지정하지 않고 학생별 가/나/다 하나를 모든 게임에 쓴다(DB 표 그대로).
- **별 기준**: 실수 0번 ⭐3, 1~2번 ⭐2, 3번 이상 ⭐1. 다시 하면 더 높은 별만 남는다.
- **장비**: 클리어하면 받고 자동으로 입는다. 눈밭은 털모자·장갑·목도리를 한 번에 받는다.
- **오비**: 걷기 2.4, 뛰기 6(칸/초). 빙판 마찰 0.06(바닥 타일별 마찰값으로 속도가 천천히 변해서, 빙판 위에서 뛰기로 바꿔도 미끄러진다). 가 길이 40칸, 나 50칸, 다 57칸.
- **타이쿤**: 방 6×4칸. 난방기와 인화성 물건(커튼·빨래·이불)이 가로세로 1칸 이내면 위험, 같은 쪽 콘센트에 3개 이상이면 '문어발'. 가=위험 2, 나·다=위험 4. 나=외출 전 전원 끄기, 다=환기(9초마다 공기 +1, 5가 되면 안내)와 대피 순서 연습. 코인은 안전하고 따뜻할 때 2.2초마다 1개, 위험을 고치면 보너스 2개.
- **눈밭**: 체온은 옷 한 벌이 없을 때마다 더 빨리 떨어지고, 쉼터에서 오른다. 0이 되면 게임오버 없이 쉼터로 옮겨 준다. 나=눈싸움 친구가 장갑 낀 뒤 눈덩이를 던져 장갑이 젖음→쉼터에서 '갈아입기', 몸 이상 신호가 뜨고 12초 안에 '어른 부르기'(안 눌러도 어른이 오지만 실수로 기록). 다=동상 손에서 '문지르기'를 고르면 이유를 알려 주고 다시 고르게 함.
- **순찰대**: 얼음 위로는 걸어갈 수 없다(부드럽게 막고 안내). 순찰 친구(NPC)가 26초 뒤 한 명을 대신 불러 준다. 나=물에 빠진 친구에 '들어가기/소리치기', 119 번호판. 다=썰매장 표지판 구분과 위치 그림 고르기.
- **음성**: 문구는 `src/data/voice/*.ts` 한 곳에 있고 글과 음성이 같은 키다. mp3가 없으면 태블릿 내장 한국어 음성으로 읽는다. 실제 mp3는 `npm run tts:generate`로 만들어 `public/audio`에 커밋한다.
- **자동 점검**: `npm test`(규칙·저장 37개), `scripts/test-sql.sh`(DB 보안), 브라우저로 4종을 끝까지 하는 점검은 `scripts/e2e-smoke.cjs`.
